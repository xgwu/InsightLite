## 5 — 已知边界（不藏进绿色构建里）

1. mock SSO（`/dev/login`）是缝线——真实 SSO 上线前不能对真实员工开放
2. 单文件存储（dashboard/prefs/connectors/feedback）适用 ≤30 人试点，多实例部署前必须换 SQLite/PG 表
3. 连接器 v2 缺口：OAuth、增量同步、cron 外置（当前进程内线程）
4. 成本闸门（FR-43 EXPLAIN 预算）未实现——一期数据量为 SQLite 种子库，风险低；接治理库（PG）前必须补
5. 静默错误率的生产口径需试点纠正数据校准（第二节校准建议 1/2）
6. 静态 tsbuildinfo/dist 等构建产物已 gitignore；`data/` 全量不入库（种子可重建）
